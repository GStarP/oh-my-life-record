# 领域文档使用规则

本文件说明 agent 探索本仓库时如何读取领域文档。

## 开始探索前

先读取：

- 根目录 `CONTEXT.md`；
- 如果存在根目录 `CONTEXT-MAP.md`，再读取其中与当前上下文相关的 `CONTEXT.md`；
- `docs/adr/` 中与当前工作范围相关的决策。

本仓库是单上下文布局，不需要查找 `src/<context>/docs/adr/`。

## 术语和决策

- 输出中的领域概念使用 `CONTEXT.md` 定义的词汇，不要随意引入同义词。
- 如果需要的概念还没有出现在术语表，先判断是否真的需要新增概念；不要为了描述实现细节扩充词汇。
- 如果方案与现有 ADR 冲突，必须明确指出冲突并说明是否需要重新打开该决策，不能静默覆盖。

## 当前文档职责

- `CONTEXT.md`：领域词汇和跨模块不变规则；
- `docs/设计文档.md`：当前产品范围和运行架构；
- `docs/adr/`：有取舍的、需要长期保留的架构决策；
- `docs/cloud-storage-format.md`：S3/R2 桶内对象格式；
