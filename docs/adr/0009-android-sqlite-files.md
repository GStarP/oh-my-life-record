# Android 壳、SQLite 与完整本地图片

日期：2026-11-02
状态：已采纳。

应用只在 Android 上使用，图片预计达到 GB 级。保留 React 界面，使用 Capacitor 接入原生 SQLite、相册、文件流、HTTP 和前台亮屏；本地始终保存完整图片，S3 保存可独立恢复的数据库快照与图片集合。

- SQLite 提供事务、全库查询与单文件快照，省去记录与模板的双份业务格式；同一建表定义供应用和回归测试使用。
- 图片独立于数据库，以不可变 ID 关联；只上传缺失文件，提交快照后才传播删除。内存只承载当前预览和小缓冲区。
- 云端仅在手动同步时访问；整库冲突只允许确认后恢复，不引入记录级合并或后台常驻任务。
- 凭证写入设备偏好，设备直接签名请求，不部署签名服务；取舍是凭证由本设备持有。

例如有 5GB 本地图片、云端只新增 200MB 时，恢复复用共同文件；若两端图片完全不同，保护当前数据的恢复过程可能需要接近双份空间。需要维护 Android 工程、设备存储和固定签名的维护。
