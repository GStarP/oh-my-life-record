# 图片：S3 为唯一事实来源，仅随手动上传

S3 是已上传图片的事实来源，IndexedDB 只暂存未上传图片；Cache Storage 尽力缓存已上传图片，提升离线可用性，但不作为业务数据或备份。浏览器淘汰缓存后，未缓存图片需重新联网读取；离线缺图不阻止记录编辑。

展示使用应用级唯一、与 React 无关的 `ImageManager`，合并列表和表单的并发读取，统一管理 Object URL，以有上限的内存换取再次显示的速度。缓存复用、淘汰及各模块职责见[图片模块边界](../设计文档.md#64-图片模块边界)。

关键取舍：**图片不自动上传**。手动同步只上传被本地记录引用的暂存图片，上传成功后先尽力把现有 Blob 写入图片缓存，再删除暂存本体，不额外查询云端是否存在同名图片。缓存失败不影响已成功的上传，已上传图片仍不进入 IndexedDB。选图后放弃记录不会在云端产生孤儿；代价是图片在手动同步前仅存在于本地。

云端图片删除仅由用户确认的「图片清理」执行；删除记录、移除图片和异常遗留都不隐式删除云端图片。接受孤儿留存于云端，换取删除路径无隐式副作用；显示、上传和清理流程见[图片设计](../设计文档.md#6-图片见-adr-0004)。
