# 冲突只允许云端覆盖（无合并、无本地回推）

同步按钮是记录与模板快照的唯一同步入口：云端版本更高则下载覆盖本地；版本一致且有本地修改则上传。冲突（云端更高且本地有未上传修改）时，任一冲突全局封锁本次同步（一票否决），须用户确认以云端覆盖冲突月或模板集合后整个同步才继续；取消则整体中止。启动/回前台仅只读检查，不拉取数据。

放弃记录级合并与「本地优先上传」，换取确定的同步方向：版本一致时上传、云端版本更高时下载。发生冲突的本地修改经用户确认后丢弃，这是接受的代价。

- 云端从未创建的分片允许首次上传。
- 云端版本低于本地已确认值属于异常，保持不读写，不自动回推本地版本。
- 例如本地已确认版本为 5：云端为 6 且本地有修改时先确认覆盖；云端为 5 时可上传修改；云端为 4 时不执行同步。
