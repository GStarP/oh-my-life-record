# 开发验证

构建环境和手机安装见 [Android 说明](../android/README.md)。本地回归不访问正式云端。

## 核心回归

```sh
pnpm test
pnpm build
```

- 真实 SQLite：事务回滚、游标分页、全库类型筛选、共享图片引用和模板创建顺序。
- 记录与表单：文件写入失败后的回收与重试，UTC+8 日分组、毫秒和 `false` / `0` 保留。
- 同步：条件提交、丢失回包、空间不足、冲突取消、安装中断与已完成图片复用。
- 显示：阶段最短展示时间及同阶段计数即时更新。
- 发布审核：取消与跨站保护、标签单独确认、输入变化拒绝，以及隔离 Git 远端上的源码推送、草稿读取、上传中断和草稿恢复。

测试只保留外部行为与必要协议约束，每个用例注释说明原因和预期。

## Android 回归

创建名为 `Sync_UI` 的独立模拟器，安装当前调试 APK。系统栏检查需要竖屏的 Android 15 或更高版本，以及 Android System WebView 140 或更高版本。显式设置设备序列号，避免操作日常设备：

```sh
ANDROID_HOME=/path/to/sdk ADB_SERIAL=emulator-5556 pnpm test:android
```

`test:android` 顺序执行界面流程与传输测试：

- 系统选图、取消、迟到引用、带图保存和离线重启。
- 搜索、同步和底部导航不被状态栏或系统导航栏遮挡。
- 模板新增、编辑、重启及快照恢复后的两处排序一致。
- 连接页面 placeholder、右上角关闭及迟到验证结果隔离。
- 同步遮罩、单行状态、固定高度、最低展示时间与长 Toast。
- 只传缺图、删除传播、恢复失败保留当前数据和杀进程后继续。
- 64×16 MiB 文件往返、原生内存、15 秒网络保护和 45 秒会话保护。

原生图片与图标用例先构建、安装测试包，再明确选择独立设备运行：

```sh
android/gradlew -p android :app:assembleDebugAndroidTest
adb -s emulator-5556 install -r android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5556 shell am instrument -w -r app.ohmylife.record.test/androidx.test.runner.AndroidJUnitRunner
```

覆盖 EXIF 旋转、大图采样、预览背压、摘要、半成品回收和不同尺寸图标的裁切安全区。用例通过不等于实际手机已验收。

## 真实 R2 隔离冒烟

凭证放在 Git 忽略的 `.env.smoke`，字段为 `R2_ENDPOINT`、`R2_BUCKET`、`R2_ACCESS_KEY_ID`、`R2_ACCESS_KEY_SECRET`。

```sh
ANDROID_HOME=/path/to/sdk ADB_SERIAL=emulator-5556 node --env-file=.env.smoke --test tests/android-r2.mjs
```

只操作随机 `_android-smoke/<UUID>/` 前缀，结束后回收测试对象。验证原生文件流、S3 条件写入、元信息和 SHA-256；不把正式快照作为覆盖或删除测试目标。

## 真机检查

- 同一签名覆盖安装后，已有记录、模板、图片、配置与未备份修改保持完整。
- 无凭证、断网和进程重启时均可本地使用，图片本体可离线显示。
- 检查启动图标、安全区、键盘、系统选图器、返回键和长列表滚动。
- 同步期间前台不自动熄屏；异常退出后可重新打开并继续本地使用。
- 文件级重试复用完成图片；空间不足、权限错误和超时会恢复可写。

例如手机新增记录后断网退出，再打开仍应看到记录和图片；恢复网络后只在手动同步时备份。
