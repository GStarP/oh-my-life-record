# 开发验证

## 本地回归

```bash
pnpm test -- --exclude tests/r2.smoke.test.ts
pnpm build
```

- 回归测试使用内存替身，不访问真实 R2；构建包含 TypeScript 检查。
- 连接与同步：验证无凭证、后台暂停与重连、过期结果隔离、请求总时限和冲突取消保留本地数据。
- 图片：验证暂存清理、内存资源共享、重建管理器后的缓存复用、缺图重试、缓存写入失败和清空范围。
- PWA：构建后执行真实 Service Worker，验证全部页面资源预缓存、内容完整性、缓存优先、更新等待和旧版保留。

## 浏览器与手机 PWA

离线检查使用生产构建；开发服务器不注册 Service Worker。

```bash
pnpm preview -- --host 127.0.0.1
```

桌面浏览器可用 localhost 检查；手机需访问已部署的 HTTPS 地址。在独立浏览器配置或测试桶中验证以下行为，生产数据不用于冲突或删除测试。

| 场景 | 操作与预期 |
|---|---|
| 无凭证启动 | 直接进入记录页；点击“已离线”才打开云端配置，空表单可取消；打开面板不聚焦输入框 |
| 完整离线安装 | 在线打开并等待 Service Worker 安装完成；此前不访问模板页。断网重开后仍可首次进入设置、模板页 |
| 本地记录与模板 | 离线创建模板、带图片的记录，关闭整个浏览器或 PWA，再打开后仍可查看与编辑；只保存本地数据 |
| 已上传图片 | 在线同步后关闭整个浏览器，再断网重开。缓存存在的图片可显示，未缓存图片只显示可重试占位 |
| 验证中取消 | 用受控请求延迟连接结果，取消后再让旧请求成功；不保存凭证、不重新打开面板 |
| 连接与同步分离 | 首次连接、恢复网络只检查状态并保留本地数据；另行点击同步才上传或下载 |
| 网络故障与恢复 | 后台失败无 toast 或弹窗；手动失败提示具体原因。本地保存不等待挂起的云端请求，恢复后可再次重连 |
| 同步中途失败 | 真正同步时禁止并发编辑；已经下载的数据及时展示，未上传内容保留，失败后可重试 |
| 冲突取消 | 手机离线修改某月，另一设备上传同月更新。手机同步时取消覆盖，本地记录、模板及待上传图片均保留 |
| 新版安装失败 | 用受控响应让资源缺失或内容校验失败；旧版仍可离线启动，图片缓存保留 |
| 新版安装成功 | 旧页面保留未保存输入；新版等待旧页面退出后激活，随后可离线启动，图片缓存保留 |

安装图标不代表资源已缓存完成。手机真机还需验证系统关闭、后台恢复和存储淘汰；桌面检查不能代替这些结果。缓存被浏览器淘汰或用户清除后需要重新联网，已上传图片不保证永久离线可用。

## 真实 R2 冒烟

仅显式运行，使用专用隔离桶。将以下字段写入被 Git 忽略的 `.env.smoke`，或通过同名进程环境变量注入（环境变量优先）：

```dotenv
R2_ENDPOINT=https://<account-id>.r2.cloudflarestorage.com
R2_BUCKET=omlr-smoke
R2_ACCESS_KEY_ID=<test-access-key-id>
R2_ACCESS_KEY_SECRET=<test-access-key-secret>
```

```bash
pnpm exec vitest run tests/r2.smoke.test.ts --mode smoke
```

- 缺少完整凭证时跳过；桶名必须以 `-smoke` 结尾。
- 桶不存在时尝试创建；无创建权限时需预先建好。
- 测试写入伪月份 `2999-12` 和随机图片，结束后清理并恢复原 manifest；不要并发运行或与其他操作共用该桶。

产品规则见[设计文档](设计文档.md)，云端格式见[存储格式](cloud-storage-format.md)。
